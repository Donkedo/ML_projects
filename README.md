# Machine Learning Projects

A collection of machine learning projects developed while learning and exploring data science, predictive modeling, and practical applications of machine learning.

## About the Repository

This repository documents my journey in machine learning through hands-on projects involving real-world datasets. It covers the complete machine learning workflow, from data preprocessing and exploratory data analysis to model development, evaluation, and deployment.

**Key areas covered:**
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering and Selection
- Feature Encoding and Scaling
- Machine Learning Model Development
- Model Evaluation and Comparison
- Data Visualization
- Model Deployment using Streamlit

## Machine Learning Workflow

The workflow varies depending on the dataset and problem statement but generally includes:

1. Data Collection and Inspection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering and Encoding
5. Feature Scaling, where required
6. Model Training and Hyperparameter Tuning
7. Model Evaluation and Comparison
8. Model Deployment and Visualization, where applicable

## Tools and Technologies

- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn, XGBoost
- **Model Deployment:** Streamlit
- **Development Environment:** Jupyter Notebook

## Evaluation Metrics

The evaluation metrics depend on the type of machine learning problem.

**Regression:**
- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)

**Classification:**
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC Score, where applicable

## Projects

### 1. Car Price Prediction using Linear Regression

**Objective:** Predict car prices using relevant vehicle features, such as brand, model, fuel type, transmission, and vehicle condition.

**Problem Type:** Regression

**Key Concepts:** Data preprocessing, exploratory data analysis, feature encoding, linear regression, and regression evaluation metrics.

### 2. Income Prediction

**Objective:** Develop a machine learning web application that predicts whether an individual's annual income exceeds $50,000 based on demographic and employment-related features.

**Problem Type:** Binary Classification

**Tools:** Python, Pandas, Scikit-learn, Streamlit

**Key Concepts:** Classification, model evaluation, feature preprocessing, and interactive model deployment.

### 3. Customer Churn Prediction

**Objective:** Build a machine learning application that predicts whether a customer is likely to discontinue a service based on demographic information, subscribed services, billing details, and contract characteristics.

**Problem Type:** Binary Classification

**Tools:** Python, Scikit-learn, Streamlit

**Key Concepts:** Classification, customer behavior analysis, feature engineering, and predictive modeling.

### 4. Breast Cancer Prediction using Machine Learning

**Objective:** Predict whether a breast tumor is benign or malignant using machine learning classification algorithms. Multiple models are trained and evaluated to compare their predictive performance.

**Problem Type:** Binary Classification

**Key Concepts:** Classification algorithms, model comparison, confusion matrices, precision, recall, and other relevant evaluation metrics.

**Note:** This is an educational machine learning project and is not intended for clinical diagnosis.

### 5. Diamond Price Prediction using XGBoost

**Objective:** Develop a machine learning web application that predicts diamond prices based on their physical characteristics.

**Problem Type:** Regression

**Tools:** Python, Pandas, Scikit-learn, XGBoost, Streamlit

**Key Concepts:** Regression modeling, feature engineering, model evaluation, and interactive deployment.
